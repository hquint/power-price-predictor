# power-price-predictor

A modular machine learning pipeline for predicting short-term electricity prices using a combination of:

- Historical power market data (from ENTSO-E)

- Weather data (from Open-Meteo)

- Time-based and engineered features

The goal is to develop a scalable, model-agnostic system that can:

- Train and evaluate models like Random Forest, Gradient Boosting, etc.

- Integrate real-world datasets in a clean, reproducible way
